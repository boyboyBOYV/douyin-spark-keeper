# 抖音私信自动续火花工具

每天自动给抖音好友发送消息续火花，带图形化界面，可自由选择要续火花的好友，可在界面中管理定时任务。

基于浏览器自动化，登录一次长期有效，全程在本机运行。

## 功能特点

- 🖥️ **图形化界面**：浏览器打开控制台，操作直观
- 👥 **好友管理**：自动读取全部好友，勾选要续火花的人
- 🔍 **搜索筛选**：快速找到指定好友，支持全选/反选
- ✏️ **自定义内容**：可修改发送内容（默认 🔥）
- ⏰ **定时任务管理**：在界面中创建、修改、启用/禁用、删除定时任务
- 📊 **运行日志**：实时查看发送进度和结果

## 快速开始

1. 下载或克隆本仓库到本地任意目录
2. 双击 `setup.bat`
3. 按提示操作：自动装环境 → 打开控制台扫码登录 → 勾选好友 → 创建定时任务
4. 完成，每天自动运行

## 图形化界面使用

双击 `run-gui.bat` 启动控制台，浏览器会自动打开 `http://localhost:37890`。

**首次使用**：
1. 点击「刷新好友」，用手机抖音扫码登录
2. 等待好友列表加载完成
3. 勾选要续火花的好友（支持搜索、全选、反选）
4. 设置发送内容（默认 🔥）
5. 点击「保存设置」
6. 在「定时任务」区域选择时间，点击「创建定时任务」
7. 点击「立即运行一次」测试效果

**定时任务管理**（在控制台右侧「定时任务」区域）：
- **创建**：选择时间 → 点击「创建定时任务」
- **修改时间**：在「修改时间」输入新时间 → 点击「保存」
- **启用/禁用**：点击「禁用」或「启用」按钮
- **删除**：点击「删除」按钮（需确认）
- 界面会显示当前状态、每天运行时间、下次运行时间

**日常管理**：
- 加了新好友 → 点击「刷新好友」重新读取
- 不想给某人发了 → 取消勾选 → 保存设置
- 改发送内容 → 修改输入框 → 保存设置
- 查看运行情况 → 右侧日志面板实时显示

## 常见问题

**1. 关闭控制台窗口后定时任务还会运行吗**

会。定时任务调用的是 `run-silent.bat`（静默运行），不依赖控制台窗口。控制台只是用来管理设置和手动运行的。

**2. 电脑关机了会错过吗**

不会。定时任务设置了「开机后自动补跑」，关机错过后下次开机会自动运行当天任务。

**3. 提示登录失效怎么办**

双击 `run-gui.bat`，在控制台点击「刷新好友」，扫码登录即可。

**4. 以后加了新好友 / 会话变多**

在控制台点击「刷新好友」重新读取，然后勾选新好友并保存。

**5. 想暂时停用自动运行但保留设置**

在控制台「定时任务」区域点击「禁用」按钮即可，需要时再点「启用」。

## 移动目录 / 换电脑

**把文件夹移到桌面或其他位置**：直接剪切粘贴即可，然后双击一次 `setup.bat`（跳过已完成的步骤，到第 5 步会自动更新定时任务路径）。

**换到另一台电脑**：

1. 把整个 `douyin-spark` 文件夹复制到 U 盘 / 网盘 / 微信传输（`.browser-profile` 登录态可以不复制，新电脑重新扫码更稳）
2. 在新电脑放到任意位置（建议桌面或文档）
3. 双击里面的 `setup.bat`，按提示操作
4. 完成，每天自动运行

## 技术栈

- Node.js + Playwright（浏览器自动化）
- 原生 HTTP 服务器（无框架依赖）
- 原生 HTML/CSS/JS 前端（无构建）
- Windows 任务计划程序（定时触发）
