# 抖音私信自动续火花工具

每天自动给抖音好友发送消息续火花，带图形化界面，可自由选择要续火花的好友，支持在界面中管理定时任务。

基于浏览器自动化，登录一次长期有效，全程在本机运行。

## 功能特点

- 🖥️ **图形化界面**：浏览器打开控制台，操作直观
- 👥 **好友管理**：自动读取全部好友，勾选要续火花的人
- 🔍 **搜索筛选**：快速找到指定好友
- ✏️ **自定义内容**：可修改发送内容（默认 🔥）
- ⏰ **定时任务管理**：在界面中添加、修改、启用/禁用、删除定时任务
- 🔥 **今日已发送标记**：今天续过的好友火焰变红，没续的变灰，一目了然
- 📦 **EXE 单文件版**：无需安装 Node.js，双击即用
- 📊 **运行日志**：实时查看发送进度和结果

## 快速开始

### 方式一：EXE 单文件版（推荐，无需环境）

1. 从 [Releases](https://github.com/boyboyBOYV/douyin-spark-keeper/releases) 下载最新版 `douyin-spark-keeper.exe`
2. 放到任意文件夹（建议单独建一个文件夹，数据会保存在这里）
3. 首次运行需要安装浏览器：在 exe 所在目录打开命令行，运行 `douyin-spark-keeper.exe`，如果提示缺少浏览器，先运行 `npx playwright install chromium`（需要 Node.js）
4. 双击 exe 启动控制台，浏览器自动打开
5. 扫码登录 → 勾选好友 → 创建定时任务

### 方式二：源码版（需要 Node.js）

1. 克隆或下载本仓库
2. 双击 `setup.bat`
3. 按提示操作：自动装环境 → 打开控制台扫码登录 → 勾选好友 → 创建定时任务

## 图形化界面使用

双击 `run-gui.bat`（源码版）或 `douyin-spark-keeper.exe`（EXE 版）启动控制台，浏览器会自动打开 `http://localhost:37890`。

**首次使用**：
1. 点击「刷新好友」，用手机抖音扫码登录
2. 等待好友列表加载完成
3. 勾选要续火花的好友（支持搜索、全选、反选）
4. 设置发送内容（默认 🔥）
5. 点击「保存设置」
6. 点击「立即运行一次」测试效果
7. 在「定时任务」区域设置每天自动运行时间

**今日已发送标记**：
- 🔴 红色火焰 = 今天已经成功续过火花
- ⚪ 灰色火焰 = 今天还没续
- 每天 0 点自动重置

**定时任务管理**：
- 创建：选择时间 → 点击「创建定时任务」
- 修改：修改时间 → 点击「保存修改」
- 启用/禁用：点击「启用」或「禁用」按钮
- 删除：点击「删除」按钮

## 常见问题

**1. 想改每天发送时间或停用**

在图形化界面的「定时任务」区域直接修改、启用/禁用或删除，无需打开任务计划程序。

**2. 提示登录失效怎么办**

启动控制台，点击「刷新好友」，扫码登录即可。

**3. 以后加了新好友 / 会话变多**

在控制台点击「刷新好友」重新读取，然后勾选新好友并保存。

**4. 关闭控制台窗口后定时任务还会运行吗**

会。定时任务调用的是静默模式（`exe --silent` 或 `run-silent.bat`），不依赖控制台窗口。控制台只是用来管理设置和手动运行的。

**5. 电脑关机了会错过吗**

不会。定时任务设置了「开机后自动补跑」，关机错过后下次开机会自动运行当天任务。

**6. EXE 版提示找不到浏览器怎么办**

EXE 版需要 Playwright 浏览器。在 exe 所在目录打开命令行，运行：
```
npx playwright install chromium
```
安装完成后再双击 exe 即可。

## 移动目录 / 换电脑

**EXE 版**：把 exe 所在的整个文件夹复制过去即可（包含 `.browser-profile` 登录态、`config.json` 配置）。如果不复制登录态，新电脑重新扫码更稳。

**源码版**：
1. 把整个 `douyin-spark` 文件夹复制到 U 盘 / 网盘
2. 在新电脑放到任意位置
3. 双击里面的 `setup.bat`，按提示操作

## 技术栈

- Node.js + Playwright（浏览器自动化）
- 原生 HTTP 服务器（无框架依赖）
- 原生 HTML/CSS/JS 前端（无构建）
- Windows 任务计划程序（定时触发）
- pkg（打包为单文件 EXE）
