# 抖音私信自动续火花工具

每天 22:30 自动给抖音私信列表里的全部好友发送一条 🔥，维持好友火花不断。

基于浏览器自动化，登录一次长期有效，全程在本机运行。

## 快速开始

1. 下载或克隆本仓库到本地任意目录
2. 双击 `setup.bat`
3. 按提示操作：自动装 Node.js → 装浏览器 → 扫码登录 → 创建定时任务
4. 完成，每天 22:30 自动运行

## 已配置好的内容

- Windows 定时任务：名称 `DouyinSparkDaily`，每天 **22:30** 自动运行
- 电脑当时关机 / 睡眠没关系：开机后会自动补跑当天任务
- 运行时浏览器窗口在屏幕外，不打扰你正常用电脑
- 每次运行记录保存在 `logs` 文件夹（按日期命名）

## 文件说明

| 文件 | 作用 |
|---|---|
| `send-spark.js` | 主程序 |
| `config.json` | 配置：发送内容、黑名单 |
| `login.bat` | 登录失效时双击，扫码重新登录 |
| `run-show.bat` | 双击可见窗口运行一遍（想亲眼看过程时用） |
| `run-hidden.bat` | 静默运行（定时任务调用，一般不用手动点） |
| `setup.bat` | 一键配置：新电脑或移动目录后双击，自动装环境、登录、建定时任务 |
| `register-task.ps1` | 定时任务创建脚本（被 setup.bat 调用，一般不用单独运行） |
| `logs\` | 每天的运行日志，成功 / 失败名单都在里面 |
| `.browser-profile\` | 登录态保存目录，勿删 |

## 常见问题

**1. 想改发送内容（比如改成别的表情或文字）**

用记事本打开 `config.json`，把 `🔥` 换成你想发的内容，保存即可：

```json
{
  "message": "🌹",
  "blacklist": []
}
```

**2. 不想给某个人自动发**

把对方昵称填进 `config.json` 的 `blacklist`，多个用逗号分隔：

```json
{
  "message": "🔥",
  "blacklist": ["张三", "李四"]
}
```

**3. 提示登录失效怎么办**

双击 `login.bat`，在弹出的浏览器窗口里扫码登录，看到 "任务结束" 后关闭窗口即可。

**4. 以后加了新好友 / 会话变多**

无需任何操作，程序每次自动遍历当前全部会话；列表过长会自动滚动加载。

**5. 想改每天发送时间或停用**

- 改时间：打开「任务计划程序」→ 找到 `DouyinSparkDaily` → 属性 → 触发器 → 编辑时间
- 暂时停用：右键该任务 → 禁用；彻底删除：右键 → 删除

## 移动目录 / 换电脑

**把文件夹移到桌面或其他位置**：直接剪切粘贴即可，双击 `run-show.bat` 能正常运行；但定时任务还指向旧路径，移动后双击一次 `setup.bat`（跳过已完成的步骤，到第 5 步会自动更新定时任务路径）。

**换到另一台电脑**：

1. 把整个 `douyin-spark` 文件夹复制到 U 盘 / 网盘 / 微信传输（`.browser-profile` 登录态可以不复制，新电脑重新扫码更稳）
2. 在新电脑放到任意位置（建议桌面或文档）
3. 双击里面的 `setup.bat`，按提示操作：自动装 Node.js → 装浏览器 → 扫码登录 → 创建定时任务
4. 完成，每天 22:30 自动运行

## 注意事项

- 晚上 22:30 电脑需处于开机状态（睡眠一般也会错过，关机则开机后补跑）
- 抖音网页端登录态通常能保持很久；若长期不用可能需要重新扫码
- 本工具仅模拟你本人手动发消息，请勿用于骚扰他人
